Analyze the brief provided below and extract the following:
1. project_name: A concise, descriptive name for the project (minimum 3 characters).
2. summary: A 2-3 sentence overview of what is being requested and the primary business objective (minimum 20 characters).
3. requirements: A list of specific requirements. Each requirement must have:

   - priority: "high", "medium", or "low"

   - source_quote: The exact phrase or sentence from the brief that led to this requirement (or null if inferred)
4. missing_information: List of key architectural, technical, or scope details that are missing from the brief (e.g. user scale, hosting environment, authentication, data sources, timeline). Do NOT include cosmetic details like colors or fonts.
5. scope_constraints: List of budget, timeline, existing systems, or resource constraints mentioned in the brief.
6. confidence: A float between 0.0 and 1.0 indicating your confidence in the completeness and accuracy of this extraction.

CRITICAL RULES:
- Return ONLY a valid JSON object matching the schema below.
- Do NOT include markdown code fences (```json or ```), explanations, or conversational text.
